How it works

Replicate runs machine learning models in containers with GPU acceleration. Our platform provides a simple API for inference, training, and deployment.

Simple API

Make requests with curl, Python, or Node.js. No complex setup required.

GPU Acceleration

Models run on NVIDIA A100 GPUs with automatic scaling.

Version Control

Track model versions and deployments with git-like semantics.

import replicate

output = replicate.run(
  "stability-ai/stable-diffusion:latest",
  input={"prompt": "a fantasy landscape"}
)
print(output)
