Introduction to Product Analytics

Learn how to capture, query, and visualize product usage data with PostHog.

PostHog's product analytics gives you the tools to understand how users interact with your product. From simple event counting to complex multi-step funnels, retention cohorts, and SQL-powered insights — all backed by ClickHouse for sub-second queries on billions of events.

Core concepts

Understanding these three concepts will help you get the most out of PostHog:

Events

Actions users take in your product. Each event has a name ($pageview, button_clicked, user_signed_up) and properties.

Persons

Unique users identified by a distinct ID. Persons accumulate properties (email, plan, company) and event history over time.

Cohorts

Groups of users defined by behavior or properties. Use cohorts to filter insights, target feature flags, or sync to external tools.

💡

Tip

Use posthog.identify() to attach user properties after login. This connects pre-login anonymous activity to the identified user.

Querying with HogQL

HogQL is PostHog's SQL dialect for querying events and persons. It extends ClickHouse SQL with product analytics primitives:

-- Funnel: Signup to Purchase
SELECT
  step,
  count() as users
FROM funnel(
  distinct_id,
  timestamp,
  event = '$pageview' AND properties.$current_url LIKE '%signup%',
  event = 'button_clicked' AND properties.$element_text = 'Get started',
  event = 'purchase_completed'
)
GROUP BY step
ORDER BY step
📘

Note

The funnel() function handles multi-step conversion analysis natively in SQL. No need to write complex window functions.

Visualizing data

Build dashboards with these insight types:

  • Trends — Line, bar, or area charts of event volume over time
  • Funnels — Multi-step conversion with dropoff analysis
  • Retention — Cohort-based returning user matrices
  • Paths — Sankey diagrams of user journeys
  • Stickiness — DAU/MAU ratios and frequency histograms
  • SQL Insights — Custom visualizations from raw HogQL
