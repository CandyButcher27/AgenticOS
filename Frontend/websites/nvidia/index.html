Frequently Asked Questions

What is CUDA-X?

−

CUDA-X is NVIDIA's collection of GPU-accelerated libraries spanning data science, deep learning, and high-performance computing, built on top of the CUDA parallel computing platform.

Do NVIDIA GPUs support on-prem deployment?

+

Yes. NVIDIA DGX systems and OVX servers are certified for on-premises data centers, offering the same software stack as cloud deployments.
