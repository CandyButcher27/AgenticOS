Quickstart — JavaScript

import { PostHog } from 'posthog-js'

const posthog = new PostHog(
  'phc_your_project_key',
  { api_host: 'https://us.i.posthog.com' }
)

posthog.capture('signup_completed', {
  plan: 'free',
  seats: 1
})

Once installed, autocapture starts collecting pageviews, clicks and form submissions — no extra code required. Use posthog.capture() for anything custom.

💡 Tip: Autocapture is on by default — you only need custom capture() calls for events that matter to your funnel.
✅ Success: Once your first event lands, PostHog builds your persons and events tables automatically.
⚠️ Warning: Don't send personally identifiable information as event properties unless your data retention policy covers it.
📘 Note: Server-side libraries are available for Python, Node, Ruby, PHP, Go and more.
