# Why Blueprint is unique

**Core mechanic:** a crosshair cursor with a live X/Y coordinate readout — the page tracks the pointer like drafting software, not like a website.

**Not shared with any other concept in this set:**
- Only concept using a coordinate-grid background + registration marks (print/drafting framing).
- Only concept where navigation and interaction are driven by *cursor position tracking* rather than click, drag, or typed input.
- Only monospace-as-display-face treatment — Terminal is also monospace, but Terminal's is a literal command shell; Blueprint's is an annotation/measurement voice with no shell, no prompt, no typed commands.
- Light/dark themes are a true material swap (navy blueprint ↔ cyanotype paper), not just an inverted palette.

**Palette fingerprint:** cyan ink accent + orange annotation accent, navy or aged-paper ground — doesn't overlap with any other concept's color story (no other build uses cyan/orange as its pair).
