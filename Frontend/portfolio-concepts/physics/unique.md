# Why Physics is unique

**Core mechanic:** the only concept with a real physics simulation — gravity, collision, momentum. Objects have mass and obey forces; nothing else in this set does.

**Not shared with any other concept in this set:**
- Only build where content ("projects") are literally throwable, physical objects rather than static or scroll-revealed elements.
- Only build with global state-altering toy controls (flip gravity, shake) that affect every element on the page at once.
- Click-vs-drag disambiguation is unique to this concept — every other concept's click targets are unambiguous (a button, a command, a fixed node).
- Palette fingerprint (pool-table green + mustard/coral/teal blocks) shares no hues with any other concept.

**Risk it deliberately avoids:** the two obvious defaults for a "playful" portfolio are a rainbow palette or a purple/blue gradient hero. This instead references one concrete physical object (a felt tabletop with wooden/plastic blocks), which reads as a chosen world rather than decoration.
