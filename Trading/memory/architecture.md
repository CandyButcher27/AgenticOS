# Architecture

## Strategy mechanics

Weekly short strangle on SPY, 2020-2025. Every week, independently:

1. **Entry day** = week's first trading day (Monday, or Tuesday if Monday
   is a holiday). Read that day's SPY close (`spot`), `^VIX` close, `^IRX`
   close.
2. **Expected move**: `EM = spot × (VIX/100) × sqrt(days_to_expiry/365)` —
   a 1-standard-deviation move estimate.
3. **Strike distance**: `strike_distance = EM × sd_multiplier` (default
   `sd_multiplier=1.0`, i.e. strikes at exactly 1 SD — this default was
   never validated until the 2D sweep, see `experiments.md`).
4. `L = spot - strike_distance`, `U = spot + strike_distance`. Strikes
   rounded outward to the nearest `strike_increment` (default $1).
5. **Premium**: Black-Scholes price at the rounded strike, using that
   week's spot/VIX/rate. Theoretical, not a real quoted price.
6. **Position**: sell 1 put + 1 call (short strangle), collect premium
   upfront.
7. **Stop-loss** (optional, `stop_loss_factor` param): trigger band =
   `spot ± (strike_distance × stop_loss_factor)`, rounded toward spot.
   Checked once per trading day (daily close only — no intraday data).
   If breached mid-week, buy back both legs same-day via Black-Scholes
   mark (spot/VIX/rate of that day, remaining time-to-expiry) instead of
   holding to expiry.
8. **Expiry day** = week's last trading day (Friday, or Thursday if
   Friday is a holiday). If never stopped out, settle at intrinsic value:
   `payout = max(0, strike_put - spot_expiry)*100 + max(0, spot_expiry - strike_call)*100`.

## Pipeline (`src/`)

- `data.py` — yfinance pull (SPY, ^VIX, ^IRX) + parquet cache in `data/`.
- `blackscholes.py` — European put/call pricing.
- `strategy.py` — `generate_weeks()` (entry pricing, steps 1-5),
  `add_stop_bounds()` (step 7's trigger band), `disable_stop()` (no-stop
  baseline — sets bounds to ±infinity, reuses the same check code path).
- `backtest.py` — `run()`: per-week loop, mid-week stop check then
  expiry settlement, builds the trade log.
- `metrics.py` — total P&L, win rate, max drawdown, Sharpe (weekly
  returns × √52), worst trade, tail loss (5th pct), return on capital.
- `main.py` — orchestrates one full run, writes `results/trades.csv`.
- `sweep_stop_loss.py` — 1D sweep over `stop_loss_factor`.
- `sweep_stop_loss_by_year.py` — same sweep, run separately per calendar
  year.
- `walk_forward.py` — fixed k vs. prior-year k, out-of-sample by year.
- `four_way_comparison.py` — no-stop / fixed k / prior-year k /
  expanding-window k, all four compared out-of-sample.
- `sweep_2d.py` — 2D grid over `sd_multiplier` × `stop_loss_factor`.

## Key assumptions (carried through every run)

- `iv_proxy` = VIX/100 — a volatility-index proxy, not SPY's own
  historical option IV.
- All premiums (entry and any stop-loss buyback) are theoretical
  Black-Scholes prices — `yfinance` has no historical options chain, so
  there's no real quoted price to use instead.
- `capital_proxy = strike_put * 100` is a sizing approximation, not real
  margin.
- No commissions, slippage, or early assignment modeling anywhere.
- Stop-loss checks are daily-close-only (no intraday data) — a gap
  through the stop mid-day is not caught until that day's close.

## Layout

`src/` pipeline modules and analysis scripts. `tests/` pytest suite.
`data/` and `results/` are gitignored, regenerated by running
`src/main.py`. `runs/` holds every saved backtest/sweep result — see
`experiments.md` for what's in each folder. `docs/superpowers/specs/`
holds the original design spec. `memory/` (this folder) is project
memory for future Claude sessions — kept in sync with `CLAUDE.md`.
