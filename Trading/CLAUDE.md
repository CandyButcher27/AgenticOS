# Trading

SPY weekly short strangle backtest. Full design:
`docs/superpowers/specs/2026-07-26-spy-strangle-backtest-design.md`.

## Memory

This project keeps a `memory/` folder alongside this file:

- `memory/architecture.md` — pipeline modules, strategy mechanics, every
  assumption baked into the numbers.
- `memory/experiments.md` — chronological log of every `runs/` entry:
  what changed, headline result, one-line takeaway.
- `memory/story.md` — narrative account of the project's journey, for
  onboarding a person (or a future session) with no prior context.

**Whenever this CLAUDE.md file is updated, update `memory/` in the same
change** — add or revise the relevant file(s) so the memory folder never
drifts out of sync with what this file claims. A CLAUDE.md edit that
isn't reflected in `memory/` is treated as incomplete.

## Key facts

- `iv_proxy` = VIX/100, not the underlying's real historical option IV.
- Premiums are theoretical Black-Scholes prices, not market fills —
  `yfinance` has no historical options chain.
- Entry = week's first trading day close, expiry = week's last trading day
  close. Handles Monday/Friday holidays without separate branches.
- `capital_proxy` = `strike_put * 100` is a sizing approximation, not real
  margin.
- Always run inside `.venv` (`.venv\Scripts\python`).

## Layout

`src/` pipeline modules, `tests/` pytest suite, `data/` and `results/` are
gitignored (regenerated by running `src/main.py`), `runs/` holds every
saved backtest/sweep result, `memory/` is project memory (see above).
